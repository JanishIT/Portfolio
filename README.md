# Janish Portfolio Website

## Deploy on GitHub Pages

1. Create a GitHub repository.
2. Upload all files.
3. Go to Settings -> Pages.
4. Select Deploy from Branch.
5. Choose main branch.
6. Save.

Your site will be published automatically.

## Customization

- Replace contact details in index.html
- Add screenshots to assets/
- Replace resume.pdf with your resume
- Add GitHub project links
- Embed labs using iframe URLs
